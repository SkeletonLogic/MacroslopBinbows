Known Rough Edges

  • Frame rate can dip while spinning the camera hard in heavy scenes.
  • Some buildings on the Palace maps have no collision.
  • Units can occasionally lock up in movement, an original MechCommander 2 bug. Jump jets usually free them.

Player Requirements

  • Windows 10 or 11, 64-bit.
  • Copy the folder to a local drive and run Play MC2 - REBONED.cmd.
  • Install Microsoft Visual C++ Redistributable x64 if Windows reports a missing DLL.
  • Delete the folder to uninstall. Bug logs/screenshots save to bug-shots.
