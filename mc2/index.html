Alpha Status

This is playable, useful, and still plainly an alpha. The point of the page is to get the build into players' hands without pretending the work is finished.

NativeRuns on modern Windows without an emulator or compatibility shim.
CampaignThe full campaign is playable and has been completed in testing.
Core SystemsSound, video, saves, salvage, pilot promotion and logistics screens work.
AdditionsFOV slider, render-distance slider, jump-jet slots on every mech, and minor visual quality-of-life work.

Known Rough Edges

  • Frame rate can dip while spinning the camera hard in heavy scenes.
  • Some buildings on the Palace maps have no collision.
  • Units can occasionally lock up in movement, an original MechCommander 2 bug. Jump jets usually free them.

Player Requirements

  • 64-bit Windows 10 or Windows 11.
  • Copy the whole folder to a local drive, such as C:\Games\MC2-REBONED, before running it.
  • Do not run it from a USB stick; the game writes saves and logs inside its folder.
  • If Windows reports a missing DLL, install the Microsoft Visual C++ Redistributable, x64.

Run It

No installer, no registry setup, no launcher account. It is a folder you run locally and delete when you are done.

Bug Reports

The folder keeps its own records in bug-shots: session logs, crash reports, and Ctrl+Alt+S screenshots. Quitting through the in-game menu produces a better log.

Package Boundary

The release asset is the game package. It should not be checked into this site repository; GitHub Releases is where the 600 MB archive belongs.

NetPlay Is In Development

NetPlay is the browser-playable branch of this work: MechCommander 2 compiled to run in a web browser, with multiplayer as the point of the project.

There is no date yet, no sign-up form, and no promised feature list. When it is ready to show honestly, it will live here without turning this static site into an account system.

Where This Comes From

Microsoft published MechCommander 2 as a shared-source release, with the source and content needed to build the game; REBONED is a rebuild of that release, not a cracked retail copy.
